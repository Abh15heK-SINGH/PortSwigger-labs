PortSwigger Web Security Academy Labs

Hands-on security testing labs completed through PortSwigger Web Security Academy.

This repository documents my practical learning journey in web application security, with a focus on understanding vulnerabilities, testing methodology, exploitation techniques, impact, and remediation.

Objectives
Build practical web application security skills
Understand vulnerabilities beyond theoretical definitions
Practice manual testing using Burp Suite
Develop a structured VAPT methodology
Document findings in a professional format
Build a reference for future security assessments and interviews
Tools
Burp Suite
Browser Developer Tools
curl
Linux command line
PortSwigger Web Security Academy

Methodology

For each lab, I document the following:

Understanding the application behavior
Identifying the injection point
Establishing a baseline request
Confirming the vulnerability
Determining the database/query structure
Exploiting the vulnerability
Verifying the impact
Documenting remediation
Recording key technical takeaways
